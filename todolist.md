# Betty Companion: to-do list

Nothing on this list is to be done until it's asked for. Tick an item off (`[x]`) once it's done and released.

- [x] **Live mode by default.** The program starts in live mode (places bets) instead of test mode.
- [ ] **Events screen on shop tills:** the cashiers' tills won't take `/` on the events screen. Press `1` to skip past the events screen, then `/` to open the time box.
- [ ] **One time entry per race time:** the time is typed again for every selection. When several selections share a time, type the time once and choose each of those selections from the same runner list.
- [ ] **Work out what the customer means.** Example: 'PP' with a time. Check which meetings race at that time and see that 'PP' fits one of them (Portman Park) instead of getting confused.
- [ ] **Look at the rules before giving up.** When something doesn't add up, check the house rules for what applies before backing out. Example: numbers, a time and a meeting are written, but no name, so it's an unnamed selection, and the meeting has no race at that time. The rules say the time takes precedence, so keep the time, ignore the meeting, and enter the bet that way.
